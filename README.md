# DEVCONF 2026 — Developer Conference Website

## Project Overview

DEVCONF 2026 is a modern and responsive developer conference landing page designed to showcase conference speakers, ticket pricing, and event highlights. The website features a clean layout and a technology-inspired visual design.

## Features

- **Navigation Bar:** Organized navigation menu with a registration button.
- **Hero Section:** Bold headline, background image, and call-to-action button.
- **Meet the Speakers:** Speaker profiles with photos, technical tracks, and professional titles.
- **Ticket Pricing:** Standard, Pro, and Team plans with a highlighted featured plan.
- **AI Challenge Section:** An original section developed with AI-assisted ideation and design.
- **Footer:** Conference branding, social media links, and copyright information.
- **Responsive Design:** Layout adapted for different screen sizes.

## Technologies Used

- HTML5
- CSS3

The project follows the assignment requirements and is developed without JavaScript or CSS frameworks.

## Learning Objectives

This project demonstrates practical knowledge of HTML structure, CSS styling, Flexbox, CSS Grid, responsive web design, and Git-based version control. It also explores the use of AI for creative ideation and the development of a conference-related website section.
